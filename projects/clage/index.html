Clage

A NEAT neuroevolution engine written from first principles, connected to a 2D grid world where evolved networks move, eat, and reproduce. I built it to understand the algorithm, then used it for controlled, reproducible experiments.

Why build NEAT from scratch

NEAT evolves both the weights and the shape of a neural network. Libraries such as neat-python hide the parts I wanted to understand: how to cross over two networks with different shapes, how to protect new structure before its weights are tuned, and how to check that a decoded network is valid. So I wrote the engine myself, then used it for small controlled experiments.

What I built

  • Engine: genomes, an innovation ledger that aligns matching genes during crossover, mutation, and speciation with the compatibility distance δ = c1·E/N + c2·D/N + c3·ΔW.
  • Decoding: a genome becomes a feed-forward network through Kahn's topological sort with deterministic tie-breaking. Cycles are rejected at decode time.
  • World: a walled 2D grid. Each organism sees 9 numbers and picks one of 4 actions (move, turn left, turn right, eat). Reproduction is a lifecycle rule based on energy, not a network output.
  • Experiments: config files that change exactly one parameter per condition, with a control and 5 seeds each; behavioral metrics such as action entropy and grid coverage; a terminal and matplotlib viewer that reads recorded JSON only.

The hard part: measuring behavior correctly

In artificial-life work it is easy to see intelligence in noise. Three measurement problems mattered most:

  • A “food alignment” metric looked like evidence of navigation, but it was confounded by food density: with more food nearby, random movement also points at food. I removed it from automatic charts and only compare it within one food condition.
  • Transition entropy first counted action pairs across the boundary between two organisms. Now it counts only pairs within one organism's trace. Results from before the fix are marked as not comparable.
  • The population is replaced by unevaluated offspring right after evaluation, so statistics are read from a per-generation record, never from the live population.

Key decision: explicit randomness

The engine's random generator comes from the seed. The world's generator is derived from the trial seed and the generation number. The same seed gives identical results, and different trials are independent. Without this, a 5-seed comparison between conditions would not mean anything.

Evidence

  • 300 tests pass in CI on Python 3.10 and 3.12, together with Ruff and mypy, on every push and pull request.
  • Every number on this page comes from a command in the README and can be reproduced on the current main.

Limitations

  • Sine regression is not solved within 300 generations, and XOR fails in 1 of 5 seeds.
  • Evolved networks stay small, and almost no organism survives all 300 ticks of a generation.
  • The food experiment shows that conditions separate, not that organisms learn over time. A longer, unshipped 100-generation run showed only a modest rise.
  • The world has no sensor for other organisms, so no metric claims cooperation, competition, or avoidance.
