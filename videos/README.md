# Portfolio video provenance

## Clage Studio demo

`clage-studio-demo.mp4` is a 39-second walkthrough assembled from timestamped, Studio-window-only UI captures and edited for brevity. It shows the authentic live ecosystem and measured neural-network inputs and activations, including input/output node inspection. No microphone or system audio is included, and there is no narration.

The download uses H.264 video and stereo AAC audio, with browser chrome removed from the captured frames. The poster is a frame from the finished video.

The music-only soundtrack is **“Soft Circuit”**, an original instrumental house track at **122 BPM**, synthesized for this demo without external samples or vocals. Instrumental house music was requested by the portfolio owner.
