  • AI & machine learning

    PyOpt

    Sep 2026 · Qwen3-4B, LoRA, Unsloth

    LoRA-tuned a 4B model to rewrite Python functions to run faster, scored by running the code. Published v1.1 run: correct 40/40 → 40/40, faster 29/40 → 36/40, median speedup 3.57× → 5.65×; out-of-distribution probe base 9/10, LoRA 8/10. Caveat: 13 of the 40 test prompts leaked from training, so this is not a clean held-out result. The split is fixed in v1.2; the model is not retrained yet.
